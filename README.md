# 📝 Postify

A clean and simple full-stack post management application built with modern technologies. Users can sign in, create posts, manage them, and enjoy a smooth UI experience across devices.

## 🔍 Overview

**Postify** is a full-stack application that enables authenticated users to manage their posts effectively. The app supports real-time updates, post ownership control, and offers a sleek interface built with the latest frontend tools.

---

## 🚀 Features

- 🔐 **User Authentication** – Secure login for personalized access.
- 👤 **Post Ownership** – Only the post's author can edit or delete it.
- 📱 **Responsive UI** – Fully optimized for both desktop and mobile devices.

---

## 🛠 Tech Stack

- ⚛️ **React with TypeScript**
- ⚡ **Vite** – Blazing-fast dev environment and bundler
- 🎨 **Tailwind CSS** – Utility-first styling framework
- 🧩 **shadcn/ui** – Accessible, modern UI component library

---

## 💻 Getting Started

To run the app locally:

```bash
# 1. Clone the repository
git clone https://github.com/OMarFRigaa/React-Project.git

# 2. Navigate into the project
cd React-Project

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

# Visit the app at:
http://localhost:5173
```
