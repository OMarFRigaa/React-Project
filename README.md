# 📝 Postify 

A clean and simple full-stack post management application built with modern technologies. Users can sign in, create posts, manage them, and enjoy a smooth UI experience across devices.

---

## 🔍 Overview

Posts App is a full-stack application that enables authenticated users to manage their posts effectively. The app supports real-time updates, post ownership, and provides a sleek interface using the latest frontend technologies.

---

## 🚀 Features

- 🔐 **User Authentication** – Secure login for personalized access.
- 👤 **Post Ownership** – Only the author can modify or remove their posts.
- 📊 **Live Post Count** – Automatically updates and tracks post numbers per user.
- 📱 **Responsive UI** – Optimized for both desktop and mobile devices.

---

## 🛠 Tech Stack

- ⚛️ **React with TypeScript**
- ⚡ **Vite** – Ultra-fast development server and bundler
- 🎨 **Tailwind CSS** – Utility-first styling framework
- 🧩 **shadcn/ui** – Accessible, modern UI component library

---
## 💻 Getting Started

To run the app locally:

```bash
# 1. Clone the repository
git clone https://github.com/OMarFRigaa/React-Project.git

# 2. Navigate into the project
cd React-Project

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
Visit: http://localhost:5173
```
